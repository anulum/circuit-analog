# Support

For questions about project scope, licensing or contributions, contact Miroslav Šotek, ANULUM, at protoscience@anulum.li.

The repository foundation is under construction. There is no released package, analogue simulation service, installation support commitment or qualified SPICE deck. Do not rely on planned records for an operating-point, jitter, ageing or yield decision.

For a technical report, provide the exact source revision, runtime environment, expected behaviour and minimal legally shareable input; never attach a customer design, a confidential foundry model deck or a capture that is not public. Keep original outcomes and state which references or environments were unavailable. See [contributing](CONTRIBUTING.md).
